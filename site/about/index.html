Why it's free.

Because writing a letter should not be a subscription.

The short version

Everyone needs a word processor, a spreadsheet and a way to show slides. Those are solved problems, and charging rent for them forever is a choice, not a necessity. We would rather make them and give them away.

MIT licensed

All of the code is under the MIT license. Use it, change it, sell it, fork it. There is no paid edition and no feature that is held back for one.

Native, not Electron

Each app is a small Rust program that opens a native window and uses the web view already on your system: WKWebView on macOS, WebView2 on Windows, WebKitGTK on Linux. Nothing bundles a browser, so an app is about 2 MB (Look, with its PDF engine and OCR, is about 14).

Light on old hardware

The interface is flat and solid, with no blur or glass effects that make older graphics hardware work hard, and one bundled open typeface (Geist, SIL Open Font License) so it looks the same everywhere. It is built to feel modern while running comfortably on older machines.

No telemetry, no accounts

The apps do not phone home. No analytics, no crash reporter, no sign-in, no ads, no upsell screens. They work offline and they never need a network. All the marketing is on this website, and none of it is in the software.

How to contribute

  • Use it and report what breaks. Open an issue with the app, your system and the file that misbehaved, if you can share it.
  • Send a pull request. Each app is a small Rust crate with a web UI on top of a shared kit; the contract is written down in docs/KIT.md in the repository.
  • Test on your platform. Windows and Linux testing is the most useful thing a stranger can do.
  • Tell people. That is how free software wins.

Honest known limits

  • This is version 0.1.1. It is young software and it has rough edges.
  • .docx, .xlsx and .pptx files open and save, but very complex documents may lose features. Keep an original around for anything important.
  • Only macOS has been run natively by hand. The Windows and Linux builds come from the same code but are untested so far, so expect them to be rougher.
  • Linux needs WebKitGTK 4.1 installed (the webkit2gtk-4.1 package on most distributions). Windows uses the WebView2 runtime that ships with current Windows.
  • The builds are not code-signed yet. On macOS, right-click the app and choose Open the first time. On Windows, choose More info, then Run anyway.
  • There is no email client and no real-time collaboration in the cloud.
  • There is no automatic updater. Download the new version when you want it.
