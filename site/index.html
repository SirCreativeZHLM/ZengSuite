You bought a computer. Then somebody wanted ten dollars a month to let you write a letter on it.

So we made the apps. Eleven of them: documents, spreadsheets, slides, a PDF reader, notes, a whiteboard, a calendar, reminders, contacts, a calculator and a text editor. They open the files you already have and save files other people can open.

They cost nothing and they will keep costing nothing. No account to make, no cloud to sign into, no trial that ends, no feature hiding behind a button that says Upgrade. The code is MIT licensed. Read it, change it, hand it to your friends.

That is the whole pitch. It is free. Go on.

Not Electron. Not a browser in a trench coat.

Each app is a small Rust program that opens a native window and uses the web view your operating system already has: WKWebView on macOS, WebView2 on Windows, WebKitGTK on Linux. No bundled copy of Chrome, so an app is about X MB and starts when you click it.

Everything works offline. The apps make no network calls and send nothing anywhere.

What is not here yet.

No email client. There is no replacement for Mail or Outlook yet.

No real-time cloud collaboration. Two people cannot type in the same document at once. Files are files: send them, or keep them in a folder you sync yourself.

This is version 0.1.0. Expect rough edges, and tell us about them. The honest list is on the About page.

It's free. That's it.
