The Notepad you outgrew.

A plain text editor that opens a huge file before you finish blinking.

Download ZengTextAll apps

What it does

  • Opens big files without choking

    Log files and exports that make other editors freeze are fine here.

  • Plain or rich, your choice

    Switch a document between plain text and simple rich text.

  • Find and replace with regular expressions

    Across the document, with a live count of matches.

  • Any encoding

    UTF-8 by default, and it can read the older encodings your files still use.

Formats

  • .txt
  • .md
  • .rtf
  • .html

The first one is what it reads and writes best.
