ZengText

The plain-text editor you outgrew.

A calm plain-text and rich-text editor that remembers every version.

Download ZengTextAll apps

Signature feature

Time-travel history

Every document keeps local snapshots as you work, thinned out automatically, with named snapshots kept. Scrub a slider through past versions, see a line-by-line diff against what you have now and restore any of them. Restoring snapshots your current text first, so even that is undoable. Snapshots live in the app's own data folder and are never uploaded.

What it does

  • Plain or rich

    Switch between plain text and rich text (rich documents save as HTML).

  • Find and replace

    With live word and character counts, tab indentation and zoom.

  • Opens what you throw at it

    Text, Markdown, logs, JSON, CSV, HTML, XML, YAML, TOML and most source files. Drop files on the window.

  • Calm by default

    Starts with an empty document and nothing else on screen.

Formats

  • .txt
  • .md
  • .log
  • .json
  • .csv
  • .html
  • .xml
  • .yml
  • .toml

The first one is the native, open format. Others are read and written as listed.

Keyboard

  • Version historyCtrlShiftH
  • FindCtrlF
  • Plain text modeCtrlShiftT
  • Bigger textCtrlPlus

Good to know

  • History is keyed by file path, so renaming a file starts a new history.
  • Snapshots store whole text and are capped at about 120 per file.
  • In rich mode find and replace is find-only.
