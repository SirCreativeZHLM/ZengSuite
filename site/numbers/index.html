What it does

  • A real formula engine

    SUM, IF, lookups, dates, text and the rest of the everyday functions, recalculating as you type.

  • Many sheets, one file

    Tabs for sheets, frozen rows and columns, sorting and filtering.

  • Charts you would put on a wall

    Bar, line, pie and scatter, live-linked to the cells they draw from.

  • Excel and CSV, both ways

    Open and save .xlsx, import and export .csv, export PDF.

Formats

  • .xlsx
  • .csv
  • .pdf
  • .znumbers

The first one is what it reads and writes best.

Keyboard

  • Edit a cellF2
  • Sum the selectionCtrlShiftT
