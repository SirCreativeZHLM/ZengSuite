Signature feature

Link Graph

An interactive map of your notes, the [[links]] between them and your #tags. It runs on its own hand-written physics with momentum panning and eased zoom, and stays smooth with 5,000 nodes. Drag nodes, hover for a preview, click to open, filter by folder or tag, or show just the neighbourhood of the note you are in. Backlinks and a Related notes strip help you find the rest.

What it does

  • Organised the way you think

    Nested folders, smart folders, tags, pinning, and instant full-text search across titles, bodies and attachment names.

  • A capable editor

    Checklists, tables, code blocks, three heading levels, Markdown shortcuts, image and file attachments, and sketch blocks with pen, marker and highlighter.

  • Daily note and related notes

    One shortcut opens today's note with a checklist and a link to yesterday. A strip under each note ranks related notes by similarity.

  • Lock a note

    Password-protected notes are encrypted with AES-256-GCM. Text and attachments are stored as ciphertext only.

  • Safe storage

    Autosave, two alternating copies of every note, and three rotating copies of the index.

Good to know

  • If you forget a locked note's password it cannot be recovered. Locked notes are searchable by title only.
  • Search covers the first 40,000 characters of each note. Renaming a note does not rewrite links that used its old title.
  • Attachments are fine up to tens of megabytes and slow beyond that, with a hard limit of 200 MB per file.
  • There is no handwriting recognition, OCR or scanning. .docx import is best effort (no footnotes, comments or text boxes).
