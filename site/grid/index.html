Signature feature

Formula X-ray

Select any cell and animated arrows flow in from the cells it uses and out to the formulas that depend on it. A card explains the formula in plain English, can trace the whole chain back to the numbers you typed in, warns about hard-coded numbers buried in formulas (and turns them into named constants), and replaces a range like B2:B10 with a readable name. Reduced-motion users get static arrows.

What it does

  • A canvas grid that stays smooth

    Stays at 60 fps on 100,000 rows, with a fill handle, multi-range selection, freeze panes, merge, find and replace across all sheets, and undo for everything.

  • A hand-written formula engine

    More than 480 functions, named ranges, structured table references, dynamic arrays (FILTER, SORT, UNIQUE, SEQUENCE), LET and LAMBDA, with incremental recalculation and cycle detection.

  • Tables, formats and data tools

    Conditional formatting, data validation with dropdowns, sort and filter, pivot summaries, text-to-columns, goal seek.

  • Charts you draw yourself

    Column, bar, line, area, pie, donut, scatter, combo and stacked charts that update live, plus sparklines.

  • Templates

    Budget, Invoice, Loan calculator, Checklist.

Good to know

  • Charts are written to .xlsx but not read back from it. Images, comments, hyperlinks and pivot caches in imported .xlsx files are ignored.
  • Pivot summaries are static tables you re-run to refresh. There are no cell comments and no print layout options such as page breaks.
  • SUBTOTAL 1 to 11 ignores filters (101 to 111 skip hidden rows). Multi-area references are not supported.
  • .xlsx output was checked with XML parsing and an independent reader, not with another spreadsheet app.
